# Цикл разработки до готовности проекта

Запусти цикл проверки целей проекта и удерживай его, пока проект
не будет доведён до состояния полной готовности (все критерии PASS).

$ARGUMENTS

## Протокол цикла

1. Вызови субагента `criteria-match`, передав описание текущего
   состояния (`$ARGUMENTS` или «запуск цикла развития, без конкретных
   изменений»).
2. Получи сводный отчёт:
   - **READY** — все критерии выполнены, цель проекта достигнута.
     Сообщи пользователю финальную сводку и заверши цикл.
   - **NOT READY** — в отчёте перечислены FAIL/WARN критерии с
     деталями. Переходи к шагу 3.
3. **Исправь нарушения**: разберись с каждым FAIL/WARN критерием из
   отчёта (анализ кода, правки, тестовые прогоны — так, как диктуют
   инструкции AGENTS.md и замечания субагентов).
4. Снова вызови `criteria-match` с описанием сделанных правок.
   Повторяй шаги 2–4, пока не получишь `READY`.
5. Если цикл не продвигается (вердикты не меняются три проверки
   подряд) — остановись и доложи пользователю: что проверено, что
   не выполняется, какие гипотезы есть. Не жги итерации впустую.

## Правила

- Цели/критерии проекта (AGENTS.md) не менять без явного согласования
  с пользователем. Если по ходу цикла выясняется, что критерий
  нереалистичен — остановись и обсуди с пользователем, а не
  редактируй сам.
- Исправления — реальный код по AGENTS.md (prettier, build, lint),
  не «заглушки» под критерии.
- После каждого подцикла исправлений соблюдай порядок работы из
  AGENTS.md: `npm run prettier` → `npm run build` → проверка результата.
