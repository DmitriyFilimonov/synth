## Правила добавления

1. Скрипт пишется в `.opencode/tools/infra/` и начинается с
   комментария: назначение, вход, выход.
2. Команда используется второй раз — значит, её место в этом каталоге.
3. Ничего не удалять без согласования: инструмент может использоваться
   другими агентами.
